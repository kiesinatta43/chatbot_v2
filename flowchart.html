🗂️ ตารางสรุปไฟล์และหน้าที่
แต่ละไฟล์ทำหน้าที่อะไรในระบบ
ภาพรวมทุกไฟล์ในโปรเจกต์ พร้อมบทบาทและความสัมพันธ์กัน
ไฟล์ หน้าที่หลัก ส่งข้อมูลให้ รับข้อมูลจาก
index.html
app.js
styles.css		 หน้าเว็บ — รับคำถามจากนักเรียน, แสดงผล, typing indicator, อ้างอิง ส่ง POST /chat ไปที่ server รับ JSON ChatResponse กลับมาแสดง
main.py FastAPI server — กำหนด endpoint /chat /health /documents เรียก search() และ answer_question() รับ HTTP request จาก browser
retriever.py ค้นหาเอกสาร — normalize คำถาม, TF-IDF cosine similarity, rerank ส่ง list[SearchResult] ให้ chatbot.py รับ question + history จาก main.py, โหลด index.pkl
chatbot.py สร้างคำตอบ — ตรวจ hardcoded, ตรวจเกณฑ์, เลือก extractive หรือ Ollama ส่ง ChatResponse กลับ main.py รับ SearchResult จาก retriever.py
documents.py อ่านไฟล์ PDF/DOCX/TXT, กรองลายน้ำ, แบ่ง chunk, กรอง noise ส่ง list[DocumentChunk] ให้ ingest.py รับเส้นทางไฟล์จาก config.py
ingest.py สร้าง Search Index — รันคำสั่ง python -m app.ingest ครั้งเดียว บันทึก data/index.pkl รับ chunks จาก documents.py
models.py กำหนด data structure — ChatRequest, ChatResponse, Citation ใช้โดยทุกไฟล์ —
config.py ค่าตั้งต้น — path ไฟล์, chunk size, top-K, backend, Ollama URL ใช้โดยทุกไฟล์ Environment variables
📌 ลำดับการทำงาน (สรุปสั้น)
ครั้งแรก: ครูวางไฟล์ใน src/ → รัน ingest.py → สร้าง index.pkl
ทุกครั้งที่ถาม: Browser → main.py → retriever.py (ค้นหา) → chatbot.py (สร้างคำตอบ) → Browser
